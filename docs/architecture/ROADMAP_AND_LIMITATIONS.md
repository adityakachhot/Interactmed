## 1. Current Verified Limitations

To ensure scientific honesty and clinical engineering rigor, the table below documents all established limitations of the current InteractMed-VLM platform:

| Functional Area | Verified Technical Limitation | Evidence in Repository | Underlying Root Cause | Clinical / Operational Impact |
| :--- | :--- | :--- | :--- | :--- |
| **Visual Grounding** | **Low Recall at Strict Overlap Thresholds ($\operatorname{Recall}@0.75 = 0.0810$):** While Recall@0.50 doubled to 49.72%, strict boundary localization remains low. | RSNA held-out test evaluation (`artifacts/rsna/runs/test_finetuned_run01/finetuned_test.json`). | Diffuse, ill-defined pneumonia consolidation margins; fixed letterbox resolution (640 px); single-box regression head. | The model correctly locates the general lesion area, but does not trace exact radiographic margins. |
| **Visual Grounding** | **Single-Box Constraint on Multi-Focal Disease:** The model outputs exactly one bounding box per query, even when multiple focal opacities are present across both lungs. | Evaluation on 901 RSNA test images containing 2,575 ground truth boxes (~2.86 boxes/image). | TransVG architecture uses a single `[REG]` token for regression rather than an anchor-based or set-prediction multi-box detector. | Multi-focal pneumonia is only partially grounded; secondary lesions are left unannotated. |
| **Visual Grounding** | **Absence of Objectness / Presence Score:** TransVG-AGPT unconditionally outputs a bounding box for every query, even on completely normal radiographs. | Tested in `tests/test_grounding_inference.py` and RSNA negative split analysis. | TransVG is a phrase grounding model, not an object detector; it assumes the queried entity exists. | Negative or normal images require an external pathology classifier before grounding. |
| **Visual Grounding** | **Single-Pathology Fine-Tuning Scope:** Fine-tuning was executed strictly on RSNA pneumonia cases under the fixed query `"pneumonia"`. | Training log in `training_history.json`; `configs/rsna_train.yaml`. | RSNA 2018 challenge contains annotations only for pneumonia opacities. | The fine-tuned model cannot be presumed to ground pneumothorax, cardiomegaly, or rib fractures with equal accuracy. |
| **Report Generation** | **The Opacity Sensitivity Ceiling (5.3% Pneumonia Recall):** In full-image evaluation, Prompt v3 detected only 5 of 94 pneumonia consolidations. | Full 250 development cohort benchmark (`expanded_cohort_full/comparison_summary.json`). | Pre-trained SigLIP vision encoder is frozen; subtle grayscale opacities produce weak visual token activations. | The production report generator misses subtle interstitial infiltrates without fine-tuned projector weights. |
| **Report Generation** | **Lower Finding Recall Trade-Off (24.8% vs 36.3%):** Prompt v3 exhibits lower micro-recall than the baseline. | Comparative audit across 250 cases (`docs/EXPANDED_REPORT_EVALUATION.md`). | Elimination of generic, speculative boilerplate text templates prevents serendipitous keyword matches. | Reports are safer and free of boilerplate hallucinations, but less sensitive to borderline findings. |
| **Report Generation** | **Single-View Lateral Limitation:** 2D frontal views lack depth information and retrocardiac / spine visualization. | Handled via deterministic sanitizer warning (`src/report_service.py:734-743`). | Local holdings consist exclusively of frontal projections (AP/PA). | Subtle retrocardiac or posterior sulcus pathologies cannot be confirmed without lateral views. |
| **Batch Processing** | **Sequential Processing Constraint (Single Worker):** Batch images are processed one by one rather than in parallel. | `src/batch_service.py` sets `ThreadPoolExecutor(max_workers=1)`. | Unified memory constraints on 16 GB Apple Silicon; concurrent 4B VLMs trigger memory swap thrashing. | Turnaround time scales linearly (~14s per image; ~140s for a full 10-image batch). |
| **Research Triage** | **Heuristic Rule Engine, Not a Learned Classifier:** Triage categories are generated by deterministic pattern matching. | `src/triage_service.py`, `configs/triage_rules.yaml`. | No institutional triage urgency ground truth exists in MIMIC-CXR or Chest-ImaGenome. | Prototype tool for research queue simulation only; **not clinically validated** for patient care. |

### Roadmap Item 1: Cloud MedGemma 4B LoRA Pilot Execution
- **Current Evidence:** Preflight checks, label masking, gradient routing, and single-batch overfit (loss 9.25 $\to$ 5.89) are verified in `scripts/train_medgemma_lora.py`. Training is in Standby Mode.
- **Why It Matters:** Parameter-efficient fine-tuning on the multimodal projector is the only proven method to overcome the opacity sensitivity ceiling without hallucinations.
- **Suggested Next Step:** Execute the 3-epoch pilot run on Google Colab Enterprise or GCP Compute Engine with an NVIDIA A100 GPU using [`notebooks/medgemma_finetune_colab.ipynb`](file:///Users/adityakachhot/interactmed/notebooks/medgemma_finetune_colab.ipynb).
- **Dependencies:** Google Cloud A100 instance, Hugging Face credentials for `google/medgemma-4b-it`.
- **Success Criteria:** Validation loss decreases below 3.5; pneumonia recall on `val_dev` increases from 5.3% to $\ge 30\%$ without increasing boilerplate collapse.
- **Main Risk:** Training loss decreases while clinical F1 degrades due to overfitting on report formatting idioms.

---

### Roadmap Item 2: Radiologist Double-Blind Triage Study
- **Current Evidence:** Transparent rule engine in `src/triage_service.py`; standardized CSV template in [`templates/triage_annotation_template.csv`](file:///Users/adityakachhot/interactmed/templates/triage_annotation_template.csv).
- **Why It Matters:** AI triage cannot make clinical claims without ground truth established by board-certified radiologists.
- **Suggested Next Step:** Distribute the 100-case development annotation template to two independent radiologists for blinded categorization and Cohen's Kappa ($\kappa$) inter-rater reliability measurement.
- **Dependencies:** Qualified clinician annotators, institutional review / IRB exemption.
- **Success Criteria:** Inter-rater agreement $\kappa \ge 0.75$; rule engine concordance with consensus panel $\ge 80\%$.
- **Main Risk:** Clinical disagreement on the urgency boundary between chronic and acute findings (e.g., stable vs acute cardiomegaly).

---

### Roadmap Item 3: Evaluation Sampling Variance & Temperature Sensitivity
- **Current Evidence:** All current evaluations use fixed `temperature=0.1`.
- **Why It Matters:** Small variations in autoregressive sampling can alter clinical keyword generation, affecting precision/recall measurements.
- **Suggested Next Step:** Run 5 repeated evaluation passes with different random seeds on `expanded_dev` to calculate standard errors and variance across all clinical metrics.
- **Dependencies:** Ollama runtime scripting, compute time (~15 hours).
- **Success Criteria:** Standard deviation of Clinical Micro-F1 across runs is $\le 0.015$.
- **Main Risk:** High generation variance on borderline opacities.

---

### Roadmap Item 4: Multi-Pathology Grounding Adaptation (MS-CXR)
- **Current Evidence:** Fine-tuning on RSNA achieved high accuracy on pneumonia (IoU 0.4530), but generalization to other conditions is unverified.
- **Why It Matters:** Clinicians query diverse pathologies, including pneumothorax, cardiomegaly, pleural effusion, and atelectasis.
- **Suggested Next Step:** Extend `scripts/train_rsna.py` to train on the 8 pathology classes in MS-CXR (764 local images, 1,056 records).
- **Dependencies:** MS-CXR local manifest (`data/processed/local_grounding_verified.csv`).
- **Success Criteria:** Mean IoU $\ge 0.40$ across all 8 pathology categories.
- **Main Risk:** Class imbalance (fewer pneumothorax examples than lung opacity).

---

### Roadmap Item 5: Multi-Box Grounding & Objectness Gating Layer
- **Current Evidence:** 901 RSNA test images contain 2,575 boxes; TransVG outputs only 1 box.
- **Why It Matters:** Bilateral pneumonia and multi-focal metastases require identifying multiple distinct anatomical regions.
- **Suggested Next Step:** Add an auxiliary binary classification head predicting lesion presence ($p_{\text{present}} \in [0, 1]$), and adapt the decoder to predict $K$ query proposals.
- **Dependencies:** Refactored TransVG forward pass in `third_party/AGPT/models/transvg.py`.
- **Success Criteria:** Zero boxes emitted when $p_{\text{present}} < 0.5$; capability to output up to 3 distinct non-overlapping boxes.
- **Main Risk:** Architectural complexity and loss of single-pass inference speed.

---

### Roadmap Item 6: Partial Backbone Unfreezing & Strict IoU Optimization
- **Current Evidence:** Current TransVG fine-tuning froze the ResNet-50 and DETR encoders, achieving $\operatorname{Recall}@0.75 = 0.0810$.
- **Why It Matters:** Strict boundary localization requires high-resolution feature maps from early convolutional layers.
- **Suggested Next Step:** Execute Stage 2 fine-tuning unfreezing the final ResNet-50 block (layer 4) and DETR cross-attention layers with a low learning rate ($5 \times 10^{-6}$).
- **Dependencies:** GPU memory management (requires gradient accumulation or A100 execution).
- **Success Criteria:** Recall@0.75 improves from 0.0810 to $\ge 0.1800$.
- **Main Risk:** Catastrophic forgetting of ClinicalBERT language representations during end-to-end backpropagation.

---

### Roadmap Item 7: Multi-View (Frontal + Lateral) Report Integration
- **Current Evidence:** Current pipeline processes frontal views only, requiring limitation disclaimers.
- **Why It Matters:** Lateral views resolve retrocardiac consolidations, posterior effusions, and thoracic spine compression fractures.
- **Suggested Next Step:** Update `POST /report/patient-friendly` to accept dual uploads (`file_frontal`, `file_lateral`) and interleave both image tokens into MedGemma.
- **Dependencies:** Multi-view pairing manifest from local MIMIC holdings.
- **Success Criteria:** Elimination of the lateral view limitation disclaimer; improved retrocardiac detection.
- **Main Risk:** Increased latency (~28s per request for 2 images).

---

### Roadmap Item 8: One-Shot Unsealing of Locked Test Cohort ($N=117$)
- **Current Evidence:** `expanded_test` (117 frontal images across 117 unique patients) is strictly locked and quarantined.
- **Why It Matters:** Unbiased, final evaluation of the platform must be conducted on unseen data after all prompt and model tuning concludes.
- **Suggested Next Step:** Once Roadmap Items 1 and 3 are complete, execute a single, one-shot evaluation on `expanded_test` without post-hoc modifications.
- **Dependencies:** Completion of development-phase model selection.
- **Success Criteria:** Test performance matches development performance within 95% Wilson confidence intervals.
- **Main Risk:** Cohort distribution shifts between dev and test.
